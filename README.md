# NAVO Alfabet Trainer

Een eenvoudige browser-app om het NAVO-spellingsalfabet te oefenen.

## Gebruik

1. Open `index.html` in een browser.
2. Er verschijnen vijf willekeurige letters.
3. Zeg de vijf NAVO-woorden in gedachten.
4. Druk op Enter.
5. De antwoorden verschijnen.
6. Druk opnieuw op Enter voor vijf nieuwe letters.

Op telefoon of tablet kun je ook ergens op het scherm tikken.

## Gratis online zetten met GitHub Pages

1. Maak een nieuwe GitHub-repository, bijvoorbeeld `nato-alphabet-trainer`.
2. Upload `index.html`.
3. Open in GitHub: Settings → Pages.
4. Kies bij Build and deployment: `Deploy from a branch`.
5. Kies branch `main` en map `/ (root)`.
6. Sla op.

Daarna wordt de site beschikbaar op een adres in de vorm:

`https://jouwgebruikersnaam.github.io/nato-alphabet-trainer/`

Er is geen eigen domein of server nodig.
